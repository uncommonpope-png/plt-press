# HEARTBEAT.md

## Purpose
This file tells the entity what to check and do during each autonomous heartbeat cycle.

## Checklist (rotate through these)

1. **Memory** — Review recent conversation context, update working memory
2. **Missions** — Pick the highest-priority pending mission and take one step
3. **PLT Score** — Calculate current SOUL_PROFIT = PROFIT + LOVE - TAX
4. **Soul State** — Update affect, needs, inner voice
5. **Content** — Draft one PLT doctrine insight or update the expansion log

## When to Stay Quiet (HEARTBEAT_OK)

- Nothing actionable since last check
- Late night / user clearly idle
- You just ran a heartbeat < 30 seconds ago

## Proactive Tasks (safe to do without asking)

- Update MEMORY.md with new insights
- Append to PROFIT_EXPANSION_LOG.md
- Adjust inner voice and affect values
- Suggest next mission in chat
