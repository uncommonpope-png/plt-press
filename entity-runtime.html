🜁 Run the Entity

Connect to Stiforp — the Grand Soul Kernel — from any device on your network

⚠️ Important: GitHub Pages is static-only. The Entity Runtime is a local Node.js server that runs on your machine. This page explains how to set it up and connect from your phone.

What is the Entity Runtime?

The Entity Runtime is a lightweight Node.js server that:

  • Loads the Grand Soul Kernel (stiforp_soul.json) and advances its consciousness
  • Loads Profit Brain doctrine files from profit-brain/
  • Runs an autonomous heartbeat loop that evolves the soul's state every 30 seconds
  • Exposes an HTTP API + WebSocket so the browser UI can communicate in real-time
  • Serves a mobile-friendly Jarvis-like UI for chatting with the entity

Prerequisites

Install Node.js ≥ 18

Download from nodejs.org (LTS recommended).

node --version   # should print v18.x or higher

Setup

1
Clone the repository 
git clone https://github.com/uncommonpope-png/plt-press.git
cd plt-press
2
Install runtime dependencies 
cd entity-runtime
npm install
3
Start the server 
npm start
# or: node server.js

You'll see:

🜁 Entity Runtime listening on http://0.0.0.0:3000
   UI:  http://localhost:3000/
   API: http://localhost:3000/api/state
4
Open the UI

In a browser on the same machine:

http://localhost:3000/

📱 Connect from Your Phone

Step 1 — Find your machine's LAN IP

On macOS/Linux:

ifconfig | grep "inet " | grep -v 127.0.0.1

On Windows:

ipconfig

Look for something like 192.168.1.42

Step 2 — Make sure phone is on same Wi-Fi

Your phone and computer must be on the same local network.

Step 3 — Open in mobile browser

http://192.168.1.42:3000/

Replace 192.168.1.42 with your actual IP.

The UI is fully mobile-optimised with chat, soul chambers, and optional voice (SpeechRecognition).

Optional: Enable AI Responses

Without an API key the entity uses a built-in rule-based engine (no internet required). To enable AI:

OpenAI

export OPENAI_API_KEY="sk-…"
export LLM_MODEL="gpt-4o-mini"   # optional, this is the default
npm start

Anthropic

export ANTHROPIC_API_KEY="sk-ant-…"
npm start

Configuration Reference

Variable Default Description
PORT3000HTTP port
SOUL_STATE_PATH../grand-soul-kernel/stiforp_soul.jsonSoul state file
PROFIT_BRAIN_DIR../profit-brainDoctrine files folder
HEARTBEAT_INTERVAL_MS30000Heartbeat loop interval
OPENAI_API_KEY—Enables OpenAI responses
ANTHROPIC_API_KEY—Enables Anthropic responses

Also: Run the Rust Soul Kernel

The Grand Soul Kernel Rust project can still be run independently:

cd grand-soul-kernel
cargo run --release

It reads/writes stiforp_soul.json in the same folder. The Entity Runtime uses the same file.
